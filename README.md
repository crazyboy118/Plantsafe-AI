PlantSafe AI
PlantSafe AI is a web application that uses AI to detect plant diseases from leaf images across five categories: Tomato, Apple, Potato, Grape, and Corn.    
Supported Plants
Tomato
Apple
Potato
Grape
Corn
Project Structure
index.html: Webpage layout and structure   
style10.css: Styling and layout rules   
app5.js: JavaScript logic and AI integration   
Tech Stack
HTML
CSS
JavaScript
AI APIs
Quick Start
Clone the repository:
Bash
git clone https://github.com/crazyboy118/Plantsafe-AI.git
