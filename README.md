🌿 PlantSafe AI

PlantSafe AI is a web development project that combines AI with plant disease detection. It supports five plant categories: Tomato, Apple, Potato, Grape, and Corn.

The project is designed to help users explore plant disease detection through an easy-to-use web interface.

🌱 Supported Plants

The application includes AI integrations for the following five plant categories:

* 🍅 Tomato
* 🍎 Apple
* 🥔 Potato
* 🍇 Grape
* 🌽 Corn

✨ Features

* AI-Powered Detection: Uses AI integrations to support plant disease detection for the available categories.
* Five Plant Categories: Supports Tomato, Apple, Potato, Grape, and Corn.
* Interactive Interface: A straightforward interface for accessing the available features.
* Web-Based Application: Built to make the functionality accessible through a browser.

🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* AI APIs

🚀 Getting Started

1. Clone the repository:

git clone YOUR_REPOSITORY_LINK

2. Open the project folder.
3. Open index.html in your browser.
4. Select a supported plant category and explore the available functionality.

Note: AI features may require an active internet connection and valid API access.
